# Registration Form - READLY

Builds a **user registration form** that validates inputs using **JavaScript** before submission.
The form includes these fields:
• Full Name
• Email Address
• Password
• Confirm Password
• Age

The Validation Requirements:
```
• Full Name - Must not be empty and contain at least 2 words.
• Email Address - Must follow a valid email format (e.g. example@domain.com).
• Password - At least 8 characters, with one uppercase letter, one number, and one special character.
• Confirm Password - Must match the Password field.
• Age - Must be 18 or older.
```

Functional Requirements:
```
• Alert error messages when an input is invalid.
• Prevent form submission if there are validation errors.
• Show a success message if all inputs are valid.
```

Extra: Personal Functionality
```
• Redirect user to a homepage only when they've been validated.
• Parse and display user's name on the homepage using URL query params.
```

Tech: HTML, CSS and JavaScript.
